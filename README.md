# Cryptocurrency Data Analysis

This project fetches live data of the top 50 cryptocurrencies using the CoinGecko API, performs basic analysis, and exports the data to an Excel file.

## 📌 Features:
✔ Fetches top 50 cryptocurrencies by market capitalization  
✔ Displays cryptocurrency name, symbol, price, market cap, and 24h change  
✔ Identifies top 5 cryptocurrencies by market cap  
✔ Calculates the average price of the top 50 cryptocurrencies  
✔ Saves data to an Excel file that updates every 5 minutes  

## 🚀 How to Run the Script:
1. **Install dependencies**  
2. **Run the script**  
3. The Excel file will be generated on your **Desktop**.

## 📂 Files:
- `crypto_data.py` → Main Python script to fetch, analyze, and save data  
- `Live_Crypto_Data.xlsx` → Live-updating Excel sheet
